# Engineering Definition of Done

Feature faqat tegishli bandlar bajarilganda tugallangan hisoblanadi:

- biznes xulqi implementatsiya qilingan;
- unit va integration testlar mavjud;
- modul chegarasi testlari o‘tadi;
- database o‘zgarishi bo‘lsa Flyway migratsiyasi mavjud;
- API o‘zgarsa OpenAPI contract yangilangan;
- authorization va permissionlar ko‘rib chiqilgan;
- shaxsiy ma’lumot maqsadi va retention ko‘rib chiqilgan;
- zarur sensitive access audit qilinadi;
- operatsion foydasi bor log va metriclar qo‘shilgan;
- failure behavior aniqlangan;
- hujjatlar va ADR yangilangan;
- secret commit qilinmagan;
- biznes correctness’ga ta’sir qiluvchi ochiq TODO qolmagan.
