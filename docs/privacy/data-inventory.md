# Shaxsiy ma’lumotlar inventari — boshlang‘ich

| Kategoriya | Misollar | Boshlang‘ich maqsad |
| --- | --- | --- |
| Identity | ism, telefon, user ID | Akkaunt va aloqa |
| Driver | haydovchi profili, verification holati | Tashuvchi ishonchi va mosligi |
| Company | kompaniya nomi, identifikatorlar, a’zo rollari | B2B akkauntni boshqarish |
| Vehicle | davlat raqami, tur, sig‘im, hujjatlar | Yukka mos transportni aniqlash |
| Location | pickup, delivery, joriy/live GPS | Matching va shipment bajarilishi |
| Communication | chat xabarlari, notification | Tranzaksiya koordinatsiyasi |
| Verification | guvohnoma va identity hujjatlari | Ishonch va compliance |
| Financial (kelajakda) | transaction ID, payment holati, invoice | To‘lov va accounting |

Flyway migratsiyasi yangi shaxsiy ma’lumot maydonini qo‘shsa, ushbu inventar ham o‘sha pull requestda yangilanadi. Har bir kategoriya uchun access, retention, audit va deletion qoidalari implementationdan oldin aniqlanadi.
